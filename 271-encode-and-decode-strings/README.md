<h2><a href="https://leetcode.com/problems/top-k-frequent-elements">Encode and Decode Strings</a></h2> <img src='https://img.shields.io/badge/Difficulty-Medium-orange' alt='Difficulty: Medium' /><hr><p>Design an algorithm to encode <strong>a list of strings</strong> to <strong>a string</strong>. The <strong>encoded string</strong> is then sent over the network and is <strong>decoded</strong> back to the <strong>original list</strong> of strings.</p>

<p>&nbsp;</p>
<p><strong class="example">Example 1:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">strs = ["Hello","World"]</span></p>

<p><strong>Output:</strong> <span class="example-io">["Hello","World"]</span></p>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">strs = [""]</span></p>

<p><strong>Output:</strong> <span class="example-io">[""]</span></p>
</div>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>0 &lt;= strs.length &lt; 100</code></li>
    <li><code>0 &lt;= strs[i].length &lt; 200</code></li>
	<li><code>strs[i]</code> contains any possible characters out of <code>256</code> valid ASCII characters..</li>
</ul>

<p>&nbsp;</p>
<p><strong>Follow up:</strong> Could you write a generalized algorithm to work on any possible set of characters?</p>
